# 🤖 AI Prompt库（10 个高频场景）

> 把课程框架全部转成 **可一键复制粘贴给 AI 的 Prompt模板**。
> 用法：复制 → 把 `【】`里的内容改成你自己的 → 发给 AI → 出稿。

---

## 🎯使用说明

每个 Prompt包含：
1. **场景**（我什么时候用）
2. **Prompt模板**（复制即用）
3. **变量说明**（【】里的内容怎么填）
4. **输出示例**（填好的样子）
5. **配套公式**（背后用的课程公式）

> 💡 **推荐用法**：用 Claude / GPT / Kimi 等。先粘贴模板，把 `【】`改成你的信息，**也可以先让 AI 反问你填什么**。

## 📍Prompt1：写朋友圈自我介绍（立人设）

**场景**：刚开始做 / 重塑形象 /朋友圈没"我"。

### Prompt模板

```
你是婉音老师课程体系下的内容营销专家。

请帮我写一条朋友圈自我介绍，要求如下：

【我的基本信息】：
-行业/职业：【如：私域营销教练、收纳师、宝妈副业】
-干了多少年：【如：8年】
-成就结果：【如：累计营收一个亿 / 帮助上万个学员增收4-7位数】
-踩坑经验：【如：曾经谈单总是翻车，把上门的客户聊跑】
-改变前后：【如：现在可以吃着火锅聊着天，用户追着我付费】
- 我的身份/初心：【如：希望帮助十万个创业者打破销售卡点】

【写作要求】：
- 用"自我介绍万能公式"：成就结果 → 帮助了多少人 →踩坑经验 →改变前后 →给自己身份
- 字数控制在200-300字
- 一条朋友圈不超过一个手机屏幕
-段落之间空一行
- 必须带"漫不经心的凡尔赛"
- 不要写成流水账
- 不要用"您"，用"你"

【输出】：
1. 一条可以直接发朋友圈的文案
2.配图建议（描述照片应该是什么样的）
3. 为什么这样写（一句话解释思路）
```

## 📍Prompt2：写一条朋友圈（卖产品 /转化）

**场景**：想发一条转化型朋友圈。

### Prompt模板

```
你是婉音老师课程体系下的内容营销专家。

请帮我写一条转化型朋友圈，要求如下：

【产品信息】：
- 产品名：【如：21天私域实战营】
-核心卖点：【如：21天实战代练 /助教1v1辅导 / 全勤返现】
-适合谁：【如：做了3个月私域但没结果的人】
- 价格/稀缺性：【如：原价9800 / 本期仅限20人 /下一期涨价3000】

【目标用户痛点】：
- 用户当前困境：【如：每天发朋友圈但没人加 /不知道如何变现】
- 用户当前状态：【如：每天很努力但看不到希望】

【写作要求】：
- 用"结果前置 + 用户痛点对比"公式：
 结果前置（你想不想要？）→ 用户多惨 → 经过我们之后 →改变结果 →结尾引发好奇（求点赞/扣关键词）
- 字数控制在300字以内
- 一条只写一个核心要点
- 不要直接讲产品，先共鸣 + 反认知 +救赎
-结尾用"价值链接点"（小而具体的福利钩子）

【输出】：
1.朋友圈文案
2.价值链接点（如：评论区扣"想"我私聊发什么）
3.配图建议
```

## 📍Prompt3：写反认知金句

**场景**：想发金句引发评论 / 加好友 /筛选客户。

### Prompt模板

```
你是婉音老师课程体系下的内容营销专家，擅长写反认知金句。

请按以下要求写【数量】条反认知金句：

【目标受众】：【如：30-40岁想转型的打工人 / 想做副业的宝妈】

【想打破的"大众错误认知"】：【如：努力就一定能成功 /朋友圈要天天发】

【想打破的"同行错误认知"】：【如：销售就是话术 / 加好友就是群发】

【金句公式】（选1-3个）：
1.什么什么的，本质是什么
2. 不是…而是…
3.重新定义
4. 三流/二流/一流结构
5.数字型
6.什么什么的，背后是什么

【写作要求】：
- 每条金句要有"冲击力"，让人停下来思考
- 不要写常识类反认知（必须是大多数人都认同、但其实是错的）
- 不要只反认知不讲解决方案（结尾要给出新视角）
- 每条50-80字

【输出】：
1. N条金句（按公式分类标注）
2. 每条配"使用场景"建议（如：适合发朋友圈 /适合直播开场）
3.配图建议（适合什么样的图片）

## 📍Prompt5：写用户案例（公众号 /朋友圈）

**场景**：有用户拿到了好结果，想帮他写案例。

### Prompt模板

```
你是婉音老师课程体系下的内容营销专家，擅长写用户案例。

请帮我写一篇用户案例文：

【用户基本信息】：
-姓名/化名：【如：小A /学员 Lisa】
-行业/职业：【如：某美妆品牌创始人】
- 加入前状态：【如：做了3年没结果 /不知道怎么线上获客】

【用户改变过程】：
-关键转折：【如：参加21天私域实战营】
-做了什么：【如：每天发朋友圈 / 做直播 / 加好友】
-多久见效：【如：3个月】

【用户结果】（用数据）：
-关键数据：【如：被动加微信3000+ /收款188万 /复购率40%】
-改变前后对比：【如：之前月入5千，现在月入15万】

【写作要求】：
- 用"用户案例文6大结构"：
1.自我介绍（你 +报告成就 +背书）
2.3个核心困扰（用户的痛点）
3. 可数据化的结果 +前后对比
4.3个主要收获（体验/改变/认知）
5.感恩的瞬间 + 用户的目标
6.合影照片或指导截图
- 字数1000-1500字
-一定要用"细节"+"对话"+"场景"
-结尾升华到价值观
- 不要自嗨，要讲用户的痛→解决→结果

【输出】：
1.完整公众号案例文
2.朋友圈宣发版（4步：结果前置→之前多惨→经过我们之后→改变结果对比+引发好奇）
3.配图建议
```

## 📍Prompt6：写个人故事开头

**场景**：公众号 /朋友圈连载 /自我介绍需要故事感。

### Prompt模板

```
你是婉音老师课程体系下的内容营销专家，擅长写个人故事。

请帮我写一个个人故事的开头（场景+结果+引发好奇）：

【我的基本信息】：
-之前的状态：【如：月薪2400的小会计，每天朝九晚九】
-现在的状态：【如：年入1000万的创业者 / 帮助上万人增收】
-跨度对比：【如：从月薪2400到月入12万 / 从小会计到操盘手】

【想传达的价值观】：【如：不追求稳定，追求人生更大可能性 / 至暗时刻能长出财富】

【故事开头类型】（7选1）：
1. 以时间开头（那是一年的冬天……）
2. 以对话开头（"你以为……其实……"）
3.场景直接开场（"会议室里28双眼睛盯着我"）
4. 对话直接开场
5. 以好奇开头（"你敢信吗？"）
6.提问开场（"凭什么他能拿到……？"）
7. 以结果开场（"三个月前我还在为房租发愁"）

【写作要求】：
- 必须有"强+弱+共鸣"（展示强大 +展示弱点 + 与用户建立联系）
-引发用户好奇（让用户想看下去）
- 字数控制在150-200字
- 可以是"标题党"（从X到X的跨度很大）

【输出】：
1.故事开头文案（2个版本供选择）

3. 这个开头适合放在哪里（朋友圈 /公众号开头 /直播开场）

## 📍Prompt7：写完整故事文（公众号 /直播稿）

**场景**：写一篇有故事感的文章 /直播稿。

### Prompt模板

```
你是婉音老师课程体系下的内容营销专家，擅长写故事。

请帮我写一篇完整的故事文：

【基本信息】：
-故事主角：【如：我 / 一个学员 / 一个虚构角色】
-故事类型：（4选1）
 A.细节 +解释 =行为意义
 B.困境 + 选择 = 我是怎样的人
 C.危机 +行动 + 结果 + 反响 = 我的特质
 D.提问 +事件 +象征 =动机

【故事4要素】（必须包含）：
-场景感
- 对话感
-内心活动
-情绪冲突

【故事万能5步结构】（必须遵循）：
1.痛点共鸣制造反差（"你以为……其实……"）
2.细节描写激发情绪（从某个物品/细节入手）
3.权威转折打破认知惯性（"直到什么时候我才明白"）
4. 产品植入（情绪的出口）
5.感性升华 +行动指令

【产品植入】（如有）：
-植入什么：【如：收纳服务 /课程 /护肤品】
- 在哪个步骤植入：【如：第4步"后来我花了X天/X万……"】

【写作要求】：
- 字数1000-2000字
-故事开头必须引发好奇
-结尾必须落核心观点 / 金句
- 不要头重脚轻（结尾必须有升华）
- 不要把4个结构混着用（选一个写透）

【输出】：
1.完整故事文
2.朋友圈连载版（如果适合，分3-5条）

## 📍Prompt10：诊断自己的朋友圈

```

3.整体观赏性：色系+排版+配图高级感？✅/❌

-给出"3条改进建议"（具体到能立刻执行的）

1.诊断报告（按10项 +7维度）

## 🎁Bonus Prompt11：一句话生成"立边界"朋友圈

**场景**：想让朋友圈自带"筛选"功能，筛掉不尊重你的用户。

### Prompt模板

```
请用以下要素，写一段"立边界"朋友圈文案：

【我的原则】：
- 我是来"找人"的，不是来推销的
- 我大大方方给，也会大大方方要
-找到对的人相互成就，错的一个也不要
-出现在别人生命里，要像一份礼物

【写作要求】：
-温和而坚定（不冷漠）
- 用第一人称
- 字数150-200字
-配图建议：自己笑得好看的高清照片
-结尾用一个金句升华

【输出】：
1.朋友圈文案（3个版本供选择）
2. 为什么这样写（一句话）
```

## 📚Bonus Prompt12：综合生成"今日朋友圈3 条"

**场景**：今天没灵感，让 AI帮我规划今天朋友圈3 条。

### Prompt模板

```
请按"朋友圈三脚架"（观赏价值 + 专业价值 +情绪价值），
帮我规划今天要发的3 条朋友圈。

【我的基本信息】：
-行业：【】
-近期动态：【如：刚开了一个新课 /学员拿到结果 / 最近在思考XX】
- 想达成的目标：【如：加好友 /卖产品 / 立人设】

【三脚架要求】（每天3-5条，三类各占一定比例）：
-观赏价值（视觉）：整体色系 / 单张照片高级感
- 专业价值（专业但不堆术语）：效果对比 / 用户案例 /业绩证言
-情绪价值（调动别人情绪）：有趣 /互动 /价值观

【写作要求】：
- 每条只表达一个核心要点
-段落之间空一行
- 每条不超过一个手机屏幕
-配图建议
- 一条带价值链接点（福利钩子）

【输出】：
1. 第1条：观赏价值（写什么 +配什么图）
2. 第2条：专业价值（写什么 +配什么图）
3. 第3条：情绪价值（写什么 +配什么图）
4.哪条最适合放"价值链接点"（为什么）
```

## 🎯使用流程建议

###Day1：选场景
看 [[00 - 内容营销朋友圈小助手（MOC入口）]] 找到今天要写什么。

###Day2：复制 Prompt
复制对应 Prompt，把 `【】`改成你自己的信息。

###Day3：发给 AI
- 用 Claude / GPT / Kimi 等
- **建议**：让 AI 反问你填什么（"为了给我更精准的输出，请先告诉我哪些信息需要补充"）

###Day4：微调 + 发布
- AI 出稿后，自己改30%（让文案带"你的味道"）
- 自查 [[04 - 人设7 大维度 +朋友圈诊断]]
-配图 + 发布

###Day5：观察数据
-点赞 /评论 /加好友
-复盘哪些公式有效
-沉淀到 [[20 -30 天朋友圈 SOP]]

## 💡让 AI 出稿质量更高的3 个技巧

1. **填具体信息**：别填"我做营销"，填"我做私域营销8年，主要帮30-40岁转型宝妈做副业，月均增收5000-10000"
2. **给参考样例**：粘贴1-2 条你喜欢的别人写的朋友圈，让 AI 学风格
3. **迭代出稿**：不要期待一次到位，"这版基础上，结尾再扎心一点 /开头再具体一点 /删掉XX"
