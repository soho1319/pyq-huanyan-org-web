# 如何在笔记里标记 Prompt（让 AI 生成按钮自动出现）

> 想让某个笔记里的 Prompt 在 web 上有 "🤖 AI 生成"按钮 +变量表单？
> 用下面的 HTML embed包裹。

## 📝标记语法

把 Prompt模板用 `<div class="prompt-toolbox">`包裹：

```markdown
<div class="prompt-toolbox">
<div class="prompt-title">Prompt1：写朋友圈自我介绍</div>
<div class="prompt-content">

你是婉音老师课程体系下的内容营销专家。

请帮我写一条朋友圈自我介绍：

【我的基本信息】：
-行业/职业：【如：私域营销教练】
-干了多少年：【如：8年】
-成就结果：【如：累计营收一个亿】
-踩坑经验：【如：曾经谈单总是翻车】
-改变前后：【如：现在用户追着我付费】
-我的身份/初心：【如：希望帮助十万创业者】

【写作要求】：
- 字数200-300字
- 一条朋友圈不超过一个手机屏幕
-段落之间空一行

【输出】：
1. 一条可以直接发朋友圈的文案
2.配图建议
3. 为什么这样写

</div>
</div>
```

## 🎯关键点

|元素 |作用 |
|---|---|
| `<div class="prompt-toolbox">` |标记为工具箱 |
| `<div class="prompt-title">` |标题（卡片上显示） |
| `<div class="prompt-content">` | Prompt模板（必含 `【变量名】`） |

## 🤖自动识别 `【变量】`

客户端 JS 会自动扫描所有 `【xxx】`出现的位置，**生成对应 input 表单**。

例如：
- `【行业】` → 生成一个 label="行业" 的 textarea
- `【我的基本信息】：` → 这只是描述文本，**不会**被识别为变量

> 💡 **技巧**：变量名用**有意义的短语**，例如 `【你的产品名】` 而不是 `【A】`。

## 📍示例：改造 AI Prompt库笔记

在 [[../内容营销朋友圈助手/30 - AI Prompt库（10场景）]] 中，每个 Prompt改成下面这样：

```markdown
## 📍Prompt1：写朋友圈自我介绍（立人设）

**场景**：刚开始做 / 重塑形象 /朋友圈没"我"。

<div class="prompt-toolbox">
<div class="prompt-title">Prompt1：写朋友圈自我介绍</div>
<div class="prompt-content">

你是婉音老师课程体系下的内容营销专家。

请帮我写一条朋友圈自我介绍：

【我的基本信息】：
-行业/职业：【行业/职业】
-干了多少年：【干了多少年】
-成就结果：【成就结果】
-踩坑经验：【踩坑经验】
-改变前后：【改变前后】
-我的身份/初心：【我的身份/初心】

【写作要求】：
- 用"自我介绍万能公式"
- 字数200-300字
- 一条朋友圈不超过一个手机屏幕
-段落之间空一行
- 必须带"漫不经心的凡尔赛"
- 不要写成流水账
- 不要用"您"，用"你"

【输出】：
1. 一条可以直接发朋友圈的文案
2.配图建议
3. 为什么这样写

</div>
</div>

###配套公式
[[02 -朋友圈公式库（11公式 +23结构）]] 公式1
```

## ✅前端展示效果

部署后，这条笔记渲染时会变成：

```
┌──────────────────────────────────────┐
│ 🛠️ Prompt1：写朋友圈自我介绍 [5 个变量] │
├──────────────────────────────────────┤
│ 我的基本信息： │
│行业/职业 [textarea]                  │
│干了多少年 [textarea]                  │
│成就结果 [textarea]                    │
│踩坑经验 [textarea]                    │
│改变前后 [textarea]                    │
│ │
│ [🤖 AI 生成文案]                       │
│ │
│ [生成结果区域]                         │
└──────────────────────────────────────┘
```

用户填完变量 → 点按钮 → 后端调 AI → 流式显示结果 → 一键复制。

## 🛠️快速批量改造

如果你想给 [[../内容营销朋友圈助手/30 - AI Prompt库（10场景）]] 的所有12 个 Prompt 加按钮，可以用这个脚本：

```bash
# scripts/add-prompt-toolbox.py
#扫描 "Prompt1：..." "Prompt2：..."等标题
# 自动包上 <div class="prompt-toolbox">包裹
```

或者手动逐个加（更精确）。

---

## 🚨注意事项

1. **HTML embed 必须严格闭合**：所有 `<div>`都要正确闭合，否则 Quartz渲染会出错
2. **不要在 Prompt模板里用 `【】` 做其他含义**（比如引用 /强调）——会被识别为变量
3. **变量名不能包含特殊字符**：用中文 /英文 /数字即可，避免 `<` `>` `&` 等
4. **如果某个变量不需要填** → 用户留空即可，会用"（未填写）"占位

## 🎁 Bonus：在 frontmatter 里标记（高级）

如果你想在 layout层面把整个笔记标记为 Prompt库：

```yaml
---
title:AI Prompt库
has-toolbox:true
toolbox-prompts:12
---
```

然后 layout组件读取这个 frontmatter，决定是否启用工具箱样式。

但这个方案要改 Quartz layout 文件，比较麻烦。**先用 HTML embed方案，够用了。**
